# Flyer to Fork — mirror

Identical to [flyer2fork.com](https://flyer2fork.com), served from a github.io
address.

It exists because `flyer2fork.com` was registered on 19 Oct 2026, and many
school, workplace and carrier filters block *newly registered domains* on sight
for their first few weeks, whatever is on them. `github.io` is long-established
and categorised, so it passes those filters.

Same page, same API, same everything. Once the main domain has aged out of the
newly-registered lists, this can go away.

Source of truth is [prodigalparadigm/flyer2fork](https://github.com/prodigalparadigm/flyer2fork).
